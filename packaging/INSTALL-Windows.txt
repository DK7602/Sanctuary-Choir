Sanctuary Choir for Windows (64-bit)
====================================

EASIEST: double-click "Sanctuary Choir Setup.exe" and follow the steps.
(Windows SmartScreen may warn because the installer isn't code-signed yet:
 click "More info" > "Run anyway".)

Manual install instead:
1. Copy "Sanctuary Choir.vst3" (the whole folder) to:
     C:\Program Files\Common Files\VST3\

2. Restart your DAW and rescan plug-ins. Load Sanctuary Choir as an effect on a vocal track.

3. "Sanctuary Choir.exe" is a standalone version: open it, choose your microphone under
   Options > Audio/MIDI Settings, and sing (use headphones to avoid feedback).

The interface uses Microsoft Edge WebView2, which is built into Windows 10 and 11.
If the window stays blank, install the "WebView2 Runtime" from Microsoft.
