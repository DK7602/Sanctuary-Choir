Sanctuary Choir for Linux (x86_64)
==================================

Copy "Sanctuary Choir.vst3" to ~/.vst3/
"Sanctuary Choir" is a standalone version (keep libonnxruntime.so, the AI singers' engine, next to it;
the .vst3 folder carries its own copy).

Recorded choir voices: copy the "SanctuaryVoices" folder to
  ~/.local/share/Sanctuary Choir/Voices/SanctuaryVoices
(mkdir -p "$HOME/.local/share/Sanctuary Choir/Voices" && cp -R SanctuaryVoices "$HOME/.local/share/Sanctuary Choir/Voices/")

Requires libwebkit2gtk-4.1 (sudo apt install libwebkit2gtk-4.1-0) for the interface.
